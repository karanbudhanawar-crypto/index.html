# NovaCalc Scientific

A responsive, client-side scientific calculator inspired by classic handheld scientific calculators.

## Run locally
Open `index.html` in a modern browser. No dependencies, build step, API key, or server required.

## Deploy on Render
This project is a static site. Set the build command to `echo "No build required"` and publish directory to `.` (repository root). No environment variables are needed.

## Features
- Arithmetic, parentheses, powers, factorial, percentage
- Trigonometric and inverse trigonometric functions
- DEG/RAD switch, logarithms, roots, constants, scientific notation
- Answer recall, calculation history, keyboard input
- Responsive layout; calculations run locally in the browser

This is an original calculator interface inspired by handheld calculator layout conventions. It is not affiliated with Casio.
